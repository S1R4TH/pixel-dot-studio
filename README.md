# Pixel Dot Studio

ブラウザだけで動くドット絵エディタです。インストールは不要で、PCでもスマホでも使えます。

**公開ページ：** https://s1r4th.github.io/pixel-dot-studio/

画像の処理はすべてお使いのブラウザの中で行われ、サーバーへ送信されることはありません。

## できること

- キャンバスは1×1〜640×640。ペン／消しゴム／塗りつぶし／スポイト／色の置き換え／対称描画でドット絵を描けます
- レイヤーとフレームを使ったアニメーション作成（再生・オニオンスキン対応）
- 画像の読み込みは無変換が基本です。サイズの違う画像は、調整画面で拡大縮小と配置を決めてからレイヤーとして追加できます
- 表示中のレイヤーの移動と拡大縮小
- 色の変換：カラーレベル／コントラストの調整、色数を指定しての減色（減色方式とディザリングの指定つき）、ビット階調への色域変換
- ゲーム機プリセット：機種を選ぶと、その機種の色域（ファミコンの固定パレットなど）がすぐに有効になります。解像度は専用ボタンから、プレビュー画面で拡縮と配置を決めて適用します
- キャンバスサイズの変更も、プレビュー画面で結果を確認してから適用します
- 書き出し：PNG／アニメGIF／スプライトシート／ICO／CUR／ANI
- プロジェクトの保存と読み込み（JSON形式）

## 使い方の流れ

1. ヘッダーの「読み込み」から画像を開くか、そのまま描き始めます
2. 上部の切替ボタンで、操作／色／変換／レイヤー／アニメの各パネルを開きます（パネル内の「？」で説明が見られます）
3. 描けたら「書き出し」から形式を選んで保存します

## 既知の制限

- アニメーションWebP／APNGの読み込みは、1コマ目のみ取り込まれます
- 読み込んだGIFのコマごとの表示時間は、全編均一のFPS（中央値）に揃えられます
- ドットは正方形のみで、縦横比の異なるドットには対応していません
- 使用色スウォッチの表示は48色までです（49色目以降はスポイトなどで拾えます）
